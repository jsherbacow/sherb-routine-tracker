# Sherb Routine Tracker — phone app

The iPhone companion to the Sherb Routine Tracker desktop widget. Add it to your home screen from Safari; it syncs check-offs with the desktop through a private sync key that each device keeps locally. No personal data is stored in this repository.

- `index.html`, `app.js`, `app.css`: the phone app
- `pair.html`: QR pairing page opened from the desktop widget
- `scriptable-widget.js`: home-screen widget script for the Scriptable app
